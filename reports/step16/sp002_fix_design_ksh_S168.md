# SP-002 fix design (ksh AI verdict, 2026-11-06; Kush decides; D-045, D-069)

**Measured scale:** 1,275,782 of 4,281,956 corpus ingredient lines (29.8 %; Food.com 1,275,153, A1 188, TASTEset 441) contain U+2044 FRACTION SLASH; shapes "9⁄9" 1,044,342 and "9 9⁄9" 231,414; 3 lines glue >= 2 digits before the slash ("11⁄2"). The legacy parser reads "1⁄4 tsp" and "1 1⁄2 cups" as a count of 1 with no unit — a silent wrong value the invented-value audit does not catch. The Step 16 rc2 path (`quantity/parse_adapter.py`) calls the same `grammar.parse_line`, so the S161 rc2 numbers are affected. Normalising at P1 scoring changes no P1 metric (N7 sensitivity block).

**Where (respects the S154 "old grammar/normaliser untouched" rule):** a `_prenormalise_v2(raw)` step at the top of `parse_quantity_v2` in `src/culinarystate/quantity/parse_adapter.py` (`(\d)\s*⁄\s*(\d)` → `\1/\2`), used for both `parse_line` and the local `normalize_text`; `ParsedQuantityV2.raw` and AST `raw` keep the original text. Bump `ADAPTER_VERSION` (`CQPO_PARSE_TO_AST_V2` → `_V2_1`) and `PIPELINE_VERSION` (→ `CQPO_RC2_GROUNDING_V1_1_DRAFT`); `NORMALIZER_VERSION` unchanged. `grammar.py`, `normalize.py`, rc1 untouched.

**Tests first** (`tests/unit/test_sp002_u2044.py`, synthetic): "1⁄4 tsp" → 1/4 tsp; "1 1⁄2 cups" → 3/2 cup; "1⁄2" → 1/2; "1 ⁄ 2 cup" → 1/2 cup; raw preserved; versions bumped; glued "11⁄2" → REFUSE (UNKNOWN AST, `AMBIGUOUS_GLUED_FRACTION`); property: any string without U+2044 parses byte-identically to the pre-change chain; legacy `parse_line`/`normalize` unchanged on U+2044 inputs (defect documented, not silently fixed). Existing tests that must stay green: test_quantity_v2_pipeline, test_step17a_quantity_stages, test_step16_rc2_dryrun, test_quantity, tests/property/test_quantity_properties (none contain U+2044).

**Changes on rerun (rc2 path):** `reports/step16/rc2_grounding_dryrun_counts.json` and S161 report numbers; the 26g census quantity block; Rung A only where an expression already carries U+2044 (Rung A's step-text `_NUM` is ASCII-only; extending it is a separate decision). **Unchanged (legacy path):** `recipe_quantity_mentions_v1.parquet` (frozen, keeps the defect), KGE `ING_MEASURED_IN_UNIT`, fdc crosswalk, rule_ner, line_link, rule_compiler, gold `_base_from_text` (P1 labels and replay). Protected EVD/COND/SRC/MEAS/SNAP are not built from these parsers. No signed record binds a quantity module (Step 35 v2 binds none; P1 commitments hash unedited labels).

**Expected direction:** rc2 mass-Q0 coverage (0.78 %) rises modestly (mass-unit fraction lines gain a unit); most Food.com fraction lines are cups/spoons and become locale-convention volumes (Q6), not Q0; unsupported/UNKNOWN counts and the legacy-vs-rc2 disagreement grow. Magnitude needs a rerun.

**Recommendation:** fix after the presentation as a new versioned rc2 result next to S161; until then every quantity figure carries the SP-002 caveat.
