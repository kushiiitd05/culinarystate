## Primary-source checks (accessed 2026-10-28)

1. [ChemTastesDB v2.1, Zenodo record 15051366](https://zenodo.org/records/15051366):
   release identification and 4,075 tastants. Local spreadsheet MD5
   `301369521e51abf5540ed3bb2d08f4d5` equals the published download checksum.
   This verifies file identity, not every taste measurement.
2. [UN Statistics M49 overview](https://unstats.un.org/unsd/methodology/m49/overview/):
   Polynesia is under Oceania, Western Asia under Asia, and Egypt under Africa.
   Applying MIXED to broad cultural Middle East tags is a project interpretation,
   not an M49 assertion about cuisines.
3. [RDKit fingerprint-generator API](https://www.rdkit.org/docs/source/rdkit.Chem.rdFingerprintGenerator.html):
   radius, bit size and chirality are explicit parameters. Local pinned runtime
   is 2026.3.6; online docs identify a later release, so the local smoke check and
   pin establish availability rather than assuming version equivalence.
4. [JSON Schema 2020-12 validation vocabulary](https://json-schema.org/draft/2020-12/json-schema-validation):
   numeric bounds use schema values; the current schemas do not compare sibling
   bounds. The review overlay implements that additional invariant.
5. [Kiryo et al., positive-unlabelled learning, NeurIPS 2017](https://proceedings.neurips.cc/paper/2017/hash/7cce53cf90577442771720a370c3c723-Abstract.html):
   distinguishes positive and unlabelled supervision. The molecule-level negative
   requirement is this review's methodological inference, not a taste-data claim
   made by that paper.
6. [FlavorGraph original paper](https://www.nature.com/articles/s41598-020-79422-8):
   the authors describe Recipe1M ingredient co-occurrence in the graph. This
   supports retaining the preregistered exclusion of those edges/embeddings from
   held-out recipe comparisons. Primary search excerpts were accessible; full
   article retrieval encountered publisher/PMC access checks in this session.
7. [scikit-learn nDCG documentation](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.ndcg_score.html):
   documents discounted gain normalised by ideal gain. The duplicate-candidate
   defect was reproduced directly from this repository's binary-gain function;
   the fix does not rely on matching a different library implementation.

2. Spot-check migration pairs, including their source ID, CID and worksheet
   Taste/Class taste fields. Record chemistry validity separately from migration.
3. Review the 50 crosswalks and supplemental collision; fill human fields only

   a proposed overlay rather than editing protected ledgers.

   reviewer identity and evidence; never backdate approval.

   bytes and obtain the required human signatures before any real evaluation.
