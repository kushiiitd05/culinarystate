Method and why the summaries are sufficient

Let beta be the three regression coefficients, C the frozen OLS covariance, s the frozen residual SD, n = 7 and nu = 4. The frozen fitter uses C = s²(X'X)^-1 and SSR_min = nu s². For coefficient j fixed at b, minimising over all nuisance coefficients gives the exact quadratic profile

SSR_profile(b) = SSR_min + s² (b - beta_j)² / C_jj.

Profiling the unknown common Gaussian variance gives

LR(b) = n log[SSR_profile(b) / SSR_min].

This algebra reconstructs the unconstrained profile from the committed summary without raw observations, refitting, a scan-width choice or a new optimiser. The 95% asymptotic likelihood interval uses LR <= chi²_1(.95) = 3.841458820694124; its half-width is sqrt(C_jj * nu * expm1(chi²_1(.95) / n)). The confidence level is a disclosed diagnostic choice, not a new acceptance threshold.

Because only four residual degrees of freedom remain, the table separately includes the Student-t interval beta_j +/- t_4(.975) sqrt(C_jj). This is finite-sample conditional inference under the fixed-design, independent, homoscedastic Gaussian-error model; it does not account for paper dependence, verification error, assay mismatch, model misspecification or extrapolation to another matrix. The t interval is wider here. The likelihood profile is exact algebraically; its chi-square confidence calibration is asymptotic.

Method references: the NIST likelihood-ratio test description gives the chi-square calibration, while NIST's linear-regression uncertainty example uses residual degrees of freedom for Student-t inference. The displayed profile identity is derived above from the frozen fitter's OLS equations, rather than inferred from an unscaled covariance condition number.
