## 1. Definitions, entities and data contracts

### 1.1 Core objects (§178–§179)
- **z_m = E_θ(m)** (L11068); factorized candidate `z_m = [z_m^struct, z_m^physchem, z_m^sensory, z_m^process]` (L11074–11080), definitions L11085–11088. Core hypothesis z^structure ≠ z^sensory ≠ z^process; "Representation quality is task-dependent" (L11092–11100). A fifth view z_m^culinary appears only in contrastive positive-pair semantics (L11244–11248).
- **Ingredient as molecule set:** M_i = {m_1..m_{n_i}} (L11356); z_i = A({z_m}) and "The aggregation function A is itself an experimental question" (L11370–11377).
- **Ingredient context vector (§12.4.9, L11636–11650):** x_ij = [presence, concentration, abundance, OAV, availability, evidence, process state, recipe context]. Stage-4 version (L13050–13061) drops "abundance", replaces "process state/recipe context" with "state, process, context" — minor field-list drift.
- **Three data regimes (L11654–11679):** A presence-only x_ij∈{0,1}; B quantitative abundance x_ij=C_ij; C weighted w_ij=f(C_ij, OAV_ij, evidence, process, context). "These must be evaluated separately." (L11679).
- **OAV_ij = C_ij / T_j** (L11451–11453); principle "abundance ≠ sensory importance" (L11459–11463).
- **Process-aware ingredient state (L11694–11726):** z_{i,t+1} = T_φ(z_{i,t}, p_t, θ_t, context_t), θ_t=[temperature, time, pH, moisture, oxygen, medium,…]; "static ingredient encoder ≠ process transition model". Cross-ref §185.2 (L15740–15766): for unchanged m, E_m(m)=z_m stays structural; what changes is c_{m,t}, presence_{m,t}, relevance_{m,t}, M_t; z_{i,t}=Agg({z_m, c_{m,t}, mask_{m,t}, evidence_{m,t}}).
- **Explicit molecule-interaction graph G_i^mol=(V_i,E_i) (L11549–11619):** node=molecule; edge="evidence-supported molecule–molecule relation" with types reacts-with, precursor-product, oxidation pathway, degradation pathway, acid-base, Maillard-related, lipid oxidation, documented sensory interaction, documented biochemical association (L11566–11574). Hierarchy atom graph→z_m; molecule-interaction graph→z_i; later ingredient/process graph→z_R (L11602–11618).
- **Ingredient multi-view (L12049–12081):** Z_i={z_i^chem, z_i^sensory, z_i^process, z_i^nutrition, z_i^context} (+ z_i^culinary in L12062); "Do not collapse too early." Task-conditioned: z_i^task=F(Z_i, task) (L12112–12116); tasks: flavor substitution, sensory retrieval, process prediction, cuisine reconstruction, nutrition optimization, FlavorTwin search (L12119–12125).
- **Missing-view mask** M_v∈{0,1} (L11996); **evidence-aware fusion** F(z^v, q^v …) and "feature value ≠ evidence confidence" (L12010–12044).
- **Missing-data tri-state (L12843):** M_ij ∈ {known, unknown, not applicable}. NOTE: coarser than header L128 four-state (ND / below-LOD / not measured / unchanged). Needs reconciliation (see §9).
- **Confidence ledger vector (L12860–12871):** q = [q_source, q_entity, q_measurement, q_process, q_mapping, q_evidence]; "Do not multiply arbitrary confidence values into one uncalibrated scalar."
- **Separation law (L12481–12491):** identity ≠ measurement ≠ state ≠ process ≠ evidence. "No model should be trained directly from loosely merged tables without provenance." (L12494).
- **Canonicalization (L12796–12831):** raw name → normalized text → alias resolution → canonical entity → ontology node; ops L12808–12816 (lowercase, punctuation, unit removal, stopword, singularization, alias mapping, n-gram, ontology lookup, manual review). Identity ≠ state; example onion (canonical) / chopped onion (form/state) / fried onion (processed state) / frying onion (event) (L12828–12832).

- Learning objectives (§178): supervised BCE multi-label (L11132–11140; "supervised learning alone should not be assumed sufficient", L11143); SSL masked SMILES/atom/bond/functional-group/local reconstruction/graph-level property/augmentation consistency (L11169–11175; "self-supervised chemical knowledge ≠ flavor-specific knowledge", L11180–11184); InfoNCE contrastive with τ (L11195–11208) and four positive-pair semantics (L11212–11220) that must "not be silently merged" (L11250); multi-task λ-weighted (L11277–11285) with fixed / normalized / uncertainty / dynamic weighting / gradient balancing / task heads / shared vs partially shared trunk (L11291–11297); transfer A frozen / B full FT / C PEFT (L11308–11323). Strategy comparison: universal vs task-specific vs multi-view-late-fusion (L11331–11333).

### 2.4 Ingredient level ladder (§12.4.12, L11734–11753)
Binary incidence → Mean/Sum pooling → Concentration-weighted pooling → OAV/evidence-weighted pooling → Deep Sets → Attention pooling → Set Transformer → Explicit molecule interaction graph → Process-conditioned interaction graph. "Do not escalate unless added complexity provides measurable value." T7 adds log-OAV-weighted, attention with OAV prior, hierarchical compound→class→ingredient (L10891); baselines bag-of-compounds + LightGBM and OAV-weighted POM average (L10892). Mixture null: **linear intensity-weighted model** (L11038; T6 L10868–10869: Snitz angle, POM mean + cosine, DREAM top ensemble).
- Known caveats per method: mean = equal importance (L11399); sum = "annotation coverage ≠ chemical richness" (L11415–11419); attention α ≠ causal contribution, validate via known aroma-actives / OAV / perturbation / attribution / expert (L11509–11520); Set Transformer "learned statistical interaction ≠ chemical reaction mechanism" (L11540–11544).

### 2.5 Fusion ladder (§12.5.13, L12132–12146)
Single-view baselines → Concatenation → Weighted fusion → Gated fusion → Late fusion → Cross-attention / multi-head → Mixture-of-experts → Task-conditioned multi-view fusion. Method risks: concatenation (one view dominates, scales, noisy/missing, no cross-view interaction, L11804–11808); late fusion advantages "interpretable, easy to ablate, robust to missing views, useful early benchmark" (L11983–11987); missing-view strategies masking / learned missing token / modality dropout / imputation / confidence-weighted / coverage-specific models (L12001–12006); number of heads/layers must be benchmarked (L11906).

### 2.6 Process layer (T8/T9)
- Baselines: Arrhenius first-order per compound; GBT on (T, t, pH, …)→concentration (L10928); T9 adds per-compound GP time-series (L10949).
- Candidates: (A) mechanistic multiresponse ODE reference; (B) CRNN/Bayesian CRNN; (C) kinetics-constrained neural ODE with T/pH/aw; (D) GNN-parameterized k, Ea; (E) ReactionT5 fine-tuned for product identity; (F) GBT black box (L10927). T9: reaction-graph neural ODE, latent ODE with species-graph decoder, temporal GNN, UDE hybrid (L10948). FROZEN reformulation of "real-time graph-node streaming" = species-level reaction network, node=species, edge=reaction, node state=concentration, conditioned on (T,t,pH,aw,O2,medium,history) (L10944).

### 2.7 Overall protocol (§183.A, L13129–13142)
simple baseline → learned representation → multi-view fusion → interaction model → process-aware model; "Every increase in complexity must pass a decision gate." Final working hypothesis (L13113–13123, "not yet frozen"): task-specific/multi-view molecular encoders + evidence-aware ingredient representation + explicit molecule-interaction modelling + process conditioning + task-conditioned fusion. MP v4.0 L717–718 summarises the same: z_m simple = fingerprints+descriptors+kNN/LR; z_i simple = mean/max + co-occurrence PMI/SVD.

## 4. Gates, promotion and stop rules (exact)

**Thread gates (§176):**
- **G0** (L10717): "passed when (1) splits are frozen and hashed; (2) the leakage audit shows no InChIKey overlap across splits and reports cross-split Tanimoto nearest-neighbor distributions; (3) noise ceilings have been estimated."
- **G1** (L10742) "freeze the view schema": "a view is kept only if its leave-one-out removal degrades at least one target task by more than the seed-to-seed standard deviation and beyond the 95% bootstrap CI, on two split types. Multi-view is frozen as the default only if it beats the best single view on ≥ 2 of 3 task families, with no significant loss on the third."
- **G2** (L10766): "freeze the 'reference baseline' (expected: ECFP4 counts + LightGBM, plus CLAMP-style fused MLP) as the mandatory comparator."
- **G3** (L10796–10798): "Freeze the default molecule encoder only if it beats the T2 reference on GS-LF and Keller under scaffold and cluster splits, with p < 0.05 (paired, 5 seeds × 5 folds) and a practically meaningful margin (proposed ≥ 0.01 macro-AUROC and ≥ 0.02 macro-AUPRC)." "A QM feature is frozen only if E3.5 shows its gain exceeds the noise control and justifies its featurization cost."
- **G4** (L10827): "adopt a pretrained encoder only if it beats both the T2 reference and the T3 scratch GNN under the Bayesian/paired test on ≥ 2 sensory tasks, at the label budgets the program will actually have."
- **G5** (L10847): "attention is frozen only if it beats the parameter-matched non-attention control on ≥ 2 datasets under the T0 protocol. Otherwise the default is sum/mean pooling (simpler, more robust)."
- **G6** (L10877): "freeze an interaction module only if it beats the linear intensity-weighted baseline beyond the CI on held-out mixtures *and* recovers injected interactions in E6.3. Otherwise freeze the linear model plus an explicit 'interaction = open' flag."
- **G7** (L10900): "freeze an aggregator only if it beats the OAV-weighted-average baseline on ingredient-level sensory labels, not only on proxy tasks. Proxy-only wins keep it at [HYPOTHESIS]."
- **G8** (L10937): "a process module is frozen only if it (1) recovers known mechanisms on simulated data; (2) extrapolates to a held-out temperature/pH within a pre-set tolerance (proposed ≤ 1.5× in-distribution error); (3) beats the black-box control out of distribution."
- **G9** (L10957): "'dynamic graph' is kept only if it beats T8's best module on held-out conditions *and* stays identifiable (parameter posteriors are not degenerate) at realistic sampling densities. Otherwise the program freezes T8 kinetics as the process layer."
