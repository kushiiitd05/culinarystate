# Fresh linker gold -- scoring plan (written BEFORE the gold is built or any model is scored)

Gold = `FRESH_LINKER_GOLD_FINAL.csv` (human independent double annotation + human adjudication; local, git-ignored; manifest committed first). No prompt, K, threshold, retriever, pool or model-selection change after the manifest. The 441 items are sealed evaluation data, never training data.

## Systems (outputs already produced on exactly these mentions before any gold existed)
L0 BGE top-1 (frozen v2 run; NIL operating point = frozen dev tau 0.862) | L1 E5 top-1 (dev tau 0.858) | L2 zero-shot bge-reranker-large cross-encoder over BGE top-10 (no frozen NIL threshold: forced-choice + continuous NIL only) | **L3 fine-tuned cross-encoder: NOT scored** (no checkpoint/configuration was frozen for this candidate set) | L4 Tev1-4B, K=5, `TEV-LINK-v0` (primary) | L5 Nimble, K=5 same task (documented alternative) | **L6 calibrated NIL combination: NOT scored** (formula and threshold were not frozen before gold).

## Scoring views (AMBIGUOUS is never given an invented answer)
- Gold classes: MATCH:<concept>, PARENT:<concept>, NONE, AMBIGUOUS. A set-valued answer exists for an AMBIGUOUS item only if the adjudicated readings text contains explicit ledger IDs (ING-xxxxxx); otherwise it is excluded from accuracy and counted.
- **View A (concept choice, forced among candidates, no NONE option):** STRICT denominator = gold MATCH; LENIENT denominator = MATCH + PARENT (a pick equal to the PARENT concept counts as acceptable). PARENT picks are also reported separately as "broader-link" rates.
- **View B (end-to-end with each system's frozen operating point):** denominator = MATCH + NONE (strict) / MATCH + PARENT + NONE (lenient); correct = pick equals gold concept, or NONE when gold is NONE. BGE/E5 use their frozen dev tau; Tev/Nimble use their default discrete choice (argmax including NONE); cross-encoder is excluded from View B (no frozen operating point).
- **View C (NIL):** positives = gold NONE, negatives = gold MATCH/PARENT; continuous scores: BGE/E5 negative top-1 cosine, cross-encoder negative max score, Tev/Nimble P(NONE): AUROC, AUPRC, and at the frozen operating point NIL recall, false-NONE rate on known concepts, specificity, balanced accuracy. No new threshold is chosen from this set.
- Retrieval vs reranking: pool = the system's own candidate list (BGE top-5 for Tev/Nimble/CE-over-5). Oracle = gold (or acceptable, lenient) concept in the pool; retrieval failure = absent; reranking failure = present but another candidate chosen. reranker efficiency = (acc_system - acc_BGE_top1) / (oracle_5 - acc_BGE_top1) on View A, reported when the denominator is positive.
- Paired bootstrap over items (5,000) for every difference vs BGE and vs the cross-encoder, and McNemar exact p; 95% CIs by bootstrap; reported by stratum S1-S6, by human confidence (both 3 / lower), mention length (<= 2 vs >= 3 tokens), candidate-pool size; latency per mention from the stored decision-model calls; failed/malformed counts. Post-hoc slices are descriptive.

## Claim gate (fixed now)
**V2-LINK-A:** Tev1-4B View A accuracy exceeds BGE top-1 AND the cross-encoder with a paired-bootstrap 95% lower bound > 0 under BOTH strict and lenient scoring, and its NIL AUROC exceeds BGE's with a paired lower bound > 0. **V2-LINK-B:** Tev point estimate above both BGE and the cross-encoder on View A (strict and lenient) but any lower bound <= 0, or Tev non-inferior (lower bound of difference vs BGE >= -0.03) with a clear NIL advantage or speed/quality Pareto position. **V2-LINK-C:** otherwise. **Tev vs Nimble:** Tev stays primary unless Nimble beats it with a paired lower bound > 0 on View A (strict and lenient) AND the latency/memory cost is accepted; otherwise equivalent -> Tev.
