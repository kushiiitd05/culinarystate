# CulinaryLinkDecision-v1 -- FINAL evaluation protocol (written and committed BEFORE the new set is sampled or annotated)

## 1. Provisional frozen student (DEV-level selection; no further sweep)
**CD-L2**: BAAI/bge-small-en-v1.5 cross-encoder (33.4M parameters), K = 10, lambda = 1.0 (gold + Tev1-4B teacher KL), NONE as an option, 6 epochs, lr 5e-5, batch 16, seeds 1-3, candidate order = BGE rank, teacher = frozen TEV-LINK-v0. Comparator **CD-L1** (same, lambda = 0). DEV: CD-L2 0.831 vs Tev 0.836 vs BGE 0.721 (forced Acc@1, n = 61). Wording: "student with teacher supervision"; NOT supported yet: that distillation causes the gain, CD-L2 > CD-L1, safe autonomous NIL, final generalisation. No change to K, lambda, architecture, encoder, teacher, optimiser, prompt, scoring or ordering. Synthetic augmentation is **POST-FINAL / v1.1**. Final checkpoints (seeds 1-3 of CD-L2 and CD-L1) are re-trained from the frozen recipe with weights saved and hashed before the set is annotated; DEV reproduction is checked, not tuned.

## 2. New sealed evaluation set (the 441-item set stays sealed and unused)
Newly sampled from benchmark gold mentions not used before (viewed linker sets and the 441 excluded): target 850 (S1 known 150, S2 alias-like 250, S3 likely novel/NIL 180, S4 ambiguous generic 120, S6 long qualified 150); strata fixed before annotation, no duplication to balance. **S5 regional/multilingual: unavailable now** (the benchmarks contain essentially no authentic regional mentions); it will be reported as unavailable unless authentic data (e.g. the RecipeDB regional API pool, if legitimately obtained) is added as a separately sealed addendum -- no LLM-generated regional variants. Sampling uses input text and ledger/gallery relations only.

## 3. Annotation
Two annotators independently, blind (no model names, no candidate provenance, shuffled candidates), then a disagreement sheet and human adjudication; final provenance HUMAN_INDEPENDENT_DOUBLE_ANNOTATED + HUMAN_ADJUDICATED. **AMBIGUOUS items must list all defensible acceptable concept IDs (acceptable_concepts = ING-x; ING-y; ...) or NONE**, enabling set-valued scoring (previous set lost 139/441 items to unscored ambiguity). Decisions: MATCH:<n> / PARENT:<n> / NONE / AMBIGUOUS(+ID list).

## 4. Frozen systems (pre-freeze manifest `CULINARY_LINK_DECISION_FINAL_FREEZE_MANIFEST.json` with checkpoint/config hashes, written before gold is opened)
BGE top-1 (frozen v2 recipe), E5 top-1, zero-shot bge-reranker-large cross-encoder, Tev1-4B (TEV-LINK-v0, K=5), Nimble (K=5), **CD-L2 (K=10)**, **CD-L1 (K=10)**. No fine-tuned cross-encoder, no calibrated NIL combination.

## 5. Questions and metrics (strict and lenient as before; AMBIGUOUS set-valued where acceptable_concepts exist)
Q1 CD-L2 vs BGE/E5 (paired bootstrap, McNemar). Q2 retention = (CD-L2 - BGE) / (Tev - BGE). Q3 CD-L2 vs CD-L1 (prospective distillation test). Q4 accuracy, latency (batch 1), parameters, GPU memory. Q5 strata: alias, held-out/NIL, head/tail (train frequency), qualified, ambiguous/set-valued, regional (if present). NIL (secondary): AUROC, AUPRC, false-NONE, recall, balanced accuracy at each system's frozen operating point; no new threshold from this set. Candidate-pool oracle and retrieval-vs-reranking failure reported (pooling caveat stated).

## 6. Gates (fixed now)
**D1-STRONG:** CD-L2 beats BGE or E5 with paired lower bound > 0 (strict and lenient), retains >= 95% of Tev's gain over BGE, is materially smaller/faster than Tev, and shows no catastrophic stratum degradation (any stratum with n >= 30 where CD-L2 is more than 15 points below BGE). **D1:** significant gain over BGE/E5 with substantial Tev retention but one secondary criterion unresolved. **D2:** improves over BGE but retains too little of Tev or the evidence is weak. **D3:** not reproduced. CD-L2 is not required to beat Tev. **DISTILL-A:** CD-L2 beats CD-L1 with paired lower bound > 0; **DISTILL-B:** numerically better, CI includes 0; **DISTILL-C:** no gain or CD-L1 better; reported separately and does not invalidate a strong student.

## 7. Order
protocol -> checkpoints frozen + hashed -> frame built -> systems run on the frame -> blinded sheets -> independent human labels -> adjudication -> gold freeze commit -> pool key opened -> one scoring run -> D/DISTILL classification -> report. CRF top-K segmentation result is preserved as a separate future `CulinarySpanDecision` hypothesis (best path 94.3% of gold spans, top-5 96.0%, 35/117 missed spans recoverable, oracle ceiling +1.55 F1) and is not started here. v1 NER untouched; no development on the sealed or new set.
